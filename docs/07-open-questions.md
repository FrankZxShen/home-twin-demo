# 07 待讨论问题

[返回首页](../README.md) · [上一章：验证计划](06-evaluation-plan.md) · [下一章：决策记录](08-decisions.md)

主线已由用户选定为地图主导、资产补全辅助。下面列出尚缺证据或实施决定的问题；形成结论后记入 [08](08-decisions.md)。

## 7.1 研究主张

| 编号 | 问题 | 需要的依据 |
| --- | --- | --- |
| Q01 | 首轮先覆盖哪些任务，长期要求是否作为主评测？ | 各任务的具体失败案例与原型成本 |
| Q02 | 换站位有用的情况在家庭任务中占多少？ | 独立采样住宅、未筛选任务和统计分母 |
| Q03 | 观测约束下的多种资产补全用于选站位，已有工作做到哪一步？ | 针对性查新，涵盖稳健视角规划与不确定地图 |
| Q04 | 多种资产补全是否优于单一地图、确定补全和纯几何扰动？ | 同地图、同候选集合、同判断器的 A 实验 |

## 7.2 方法必须明确的接口

| 编号 | 问题 | 影响 |
| --- | --- | --- |
| Q05 | 视频尺度、墙体、门和地面如何恢复？ | 地图质量与坐标一致性 |
| Q06 | 资产怎样对齐、裁剪和约束？哪些表面固定，哪些允许扰动？ | 目前“观察部分完全一致”与几何扰动尚未形成一致的算法定义 |
| Q07 | 使用哪个判断模型，是否加入渲染参照？ | 正确率、校准、响应时间与成本 |
| Q08 | 目标部分可见、遮挡、模糊并存时怎样确定标签？ | 四选一标签的可复现性 |
| Q09 | 软选项概率怎样转为观测似然？ | 贝叶斯更新与重复证据处理 |
| Q10 | 未知空间怎样参与可见度、通行性和误差采样？ | 补全与单一地图对照的公平性 |

## 7.3 实验与投入

| 编号 | 问题 | 需要形成的决定 |
| --- | --- | --- |
| Q11 | 先导样本与正式样本怎样选择？ | 住宅、目标区域、任务数量及总体统计方式 |
| Q12 | 哪些论文完整复现，哪些仅作策略参考？ | 来源、实现范围与统一协议 |
| Q13 | 开发、校准和测试如何按住宅隔离？ | 固定划分、参数选择范围和测试前冻结阈值 |
| Q14 | 原型在哪台机器运行，使用什么接口？ | GPU、仿真平台、模型及下载/API 预算 |
| Q15 | H4 无收益时如何处理主线？ | 依据测量结果重新选方向，不能自动把未验证的评测设计算作贡献 |

## 7.4 记录方式

每条讨论记录问题编号、当前做法、建议、理由和证据，区分确定结论与缺失信息。方法改动同步检查正文、图、工具和实验。协作方式见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
