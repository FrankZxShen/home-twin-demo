## 7.4 一条讨论结论需要包含什么

- 问题编号及对应文档、图分区。
- 支持或反对当前做法的理由。
- 论文、数据、小实验或代码证据。
- 当前结论，以及尚缺的信息。
- 如需修改，指出正文、图、工具表或实验计划中受影响的位置。

GitHub 的讨论模板已放在 `.github/ISSUE_TEMPLATE/research-discussion.md`，协作方式见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
