## 8.3 后续决策的记录方式

每条决策记录日期、关联问题编号、结论、理由与证据、影响的文件，以及关联 Issue 或 PR。结论有后续变化时，以新记录说明替代关系，保留原记录的依据。

尚未决定的内容继续留在 [07 待讨论问题](07-open-questions.md)。只有有测量记录的观察才能写为实验结果。
