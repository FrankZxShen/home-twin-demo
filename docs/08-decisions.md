## 8.1 当前有效约定

| 约定 | 理由 |
| --- | --- |
| 导览视频重建的语义地图是主要表示 | 观测到的几何直接参与选站位和现场判断 |
| 相似资产补未知部分，形成多个可能场景 | 检验未观测形状差异是否影响站位选择 |
| 补全服从已有观测，冲突处理待具体实现 | 相似资产不能覆盖实测证据 |
| 到站判断可调用 VLM 或 Jev 式工具，渲染参照可选 | 判断器与资产补全的效果分别验证 |
| 第一阶段要求固定，物体在任务之间变化 | 控制状态变化来源 |
| 要求绑定物体，暂停与撤销分开，只有主人能撤销 | 物体移动后仍可在新位置恢复 |
| 分别报告违反要求与无谓绕行 | 保留两种相反错误的实际代价 |
| 不训练导航策略，开发数据用于误差估计和校准 | 本轮检验执行时的取证机制 |

这些是用户选定或现有方案采用的工作设定，尚非 co-author 共同审议结果。
