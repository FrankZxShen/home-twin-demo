## 10.2 引用与主张

| 检查项 | 发现 | 处理与依据 |
| --- | --- | --- |
| EvolvingNav 的复查能力 | “不会换位置去看”不受原文支持 | 改为已有可见度更新和多视角复查；0.70 不是永久排除阈值。见 [A.4](https://arxiv.org/html/2609.39166v4) |
| 主动感知方法的地图假设 | “默认地图正确”与其不确定性建模冲突 | 明确其地图不确定性、相机主动观察和底盘轨迹优先级。见 [V-A、V-B](https://arxiv.org/html/2610.29964v1) |
| NavPatch 的超时 | 20 秒是有效更新后的补丁生命周期，不是物体消失证明 | 保留超时策略作对照，不直接断言它必然违反纸箱要求。见 [IV-F、IV-G](https://arxiv.org/html/2609.14543v1) |
| Jev 的输入与概率 | 只支持文字的说法已过时；接口概率不能视为本领域已校准 | 标明实验性图像输入和另行校准要求。见[官方公告](https://typesafe.ai/blog/jev-1-14)、[接口文档](https://docs.typesafe.ai/primitives) |
| 创新依据 | 已有工作覆盖主动感知、遮挡证据和场景变体 | 将贡献改为待检验的具体组合，保留针对性查新任务 |
| 量化配置 | K = 20、前 5 名、Q20、样本量和预算均来自方案 | 全部标为计划值，无实验结果 |

## 10.3 仍待解决的方法问题

| 问题 | 影响 | 当前处理 |
| --- | --- | --- |
| 观察部分“完全一致”与位置等几何扰动并存 | 补全机制尚不能直接实现 | 待明确固定表面、误差容差、裁剪和可变参数；见 Q06 |
| A 的完整评分依赖 B 的判断器标定 | 原阶段顺序存在数据依赖 | 先做几何检查，标定后再验证完整 ρ 评分 |
| 只选择关键位置检验 H1 | 无法估计日常家庭中的发生比例 | 分开报告受选样本效果和未筛选样本的频率 |
| 范围覆盖率高 | 很宽的候选范围也能覆盖真值 | 同时报范围宽度和最终选位效果 |
| 看到测试结果后再定成功标准 | 会使结论依赖测试数据 | 改为开发／先导数据定标准，最终测试前固定 |
| 纸箱消失但遮挡物仍堵路 | 纸箱状态可能不改变行动 | 成对验证路线差异，排除不能支持该主张的配置 |
| 单一地图对照能力不足 | 无法归因于多种补全 | 保留自由选站位、未知区域和相同判断器；明确确定补全及无资产扰动的比较项 |

这些问题已在方法、验证计划和待讨论项中公开，未编造实现或测量结果。
