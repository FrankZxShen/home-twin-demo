# 01 问题与任务

[返回首页](../README.md) · [下一章：核心 idea](02-idea.md)

## 1.1 研究问题

家里的东西会移动、会被遮挡，机器人的家庭记忆会过时。机器人怎样用少量观察，确认当前任务依赖的信息，再完成任务？

这里的“确认”包含三件事：判断是否有必要检查，决定去哪里观察，以及判断这次观察到底说明了什么。

## 1.2 贯穿全文的例子

主人说：“这个纸箱里有易碎物品，经过时保持一米距离。”之后又说：“去卧室帮我找水杯。”去卧室要经过纸箱所在的走廊，打开的柜门可能遮住纸箱。

| 家里实际发生的事 | 机器人应该怎么处理 |
| --- | --- |
| 纸箱在原位，能看见 | 继续保持一米距离 |
| 纸箱在原位，被柜门挡住 | 保留不确定性，必要时换位置观察 |
| 确认纸箱已离开原位置 | 暂停原位置的避让，让原位置恢复通行 |
| 在别处认出同一个纸箱 | 在新位置恢复避让 |
| 看到另一个相似纸箱 | 先判断身份，避免把要求绑定错对象 |

“纸箱搬走”改变要求的执行位置；主人明确取消，才撤销这条要求。

## 1.3 包含哪些任务

| 任务 | 需要确认的信息 |
| --- | --- |
| 找物 | 水杯是否在某个区域，区域是否已经看清 |
| 去某处 | 路线相关物体和通行条件是否仍然成立 |
| 家庭状态问答 | 纸箱是否还在走廊、卧室是否有水杯 |
| 长期要求 | 绑定的物体在哪里，当前要求应在哪里执行 |

天气、日程等不依赖家庭物理状态的问题交给外部工具处理。

## 1.4 第一阶段采用的设定

- 一台机器人，先在仿真中运行。
- 机器人拥有该住宅的历史导览视频，地图不完整且可能过时。研究的是有历史地图的家庭取证；陌生住宅导航泛化不在本轮范围内。
- 物体可以在两个任务之间变化，单个任务执行期间保持不变。
- 主人的真实要求固定；偏好变化放到后续阶段。
- 指令先用固定模板解析，保留“都不符合”的出口。
- 机器人执行任务时使用可获得的观测；模拟器真值用于离线标注、误差测量和评估。
- 主人没有干预只算弱证据，记录主人是否在看、是否来得及反馈。

纸箱例子需成对构造“仍在”和“移走”两种配置，并确认其对应的可行路线确实不同。如果柜门本身已经迫使机器人同样绕行，纸箱状态就不会改变路线，这个配置不能用来支持导航收益。

## 1.5 怎样判断任务做得好

分别报告违反要求和无谓绕行，再报告任务成功率、回答正确率、观察路程、提问次数和用时。把两类错误分开，才能看出系统是过早放弃要求，还是一直保守绕行。
