# 06 验证计划

[返回首页](../README.md) · [上一章：相关工作](05-related-work.md) · [下一章：待讨论问题](07-open-questions.md)

本页归纳已有原型方案中的验证顺序。所有指标均待测；样本数量和默认参数是待共同确认的计划值。

## 6.1 先检查是否有值得换站位的情况

比较原路线、预设观察位置与额外移动后的观察位置，统计哪些目标区域能够从“看不清”变为“看清”。同时比较孪生预测的露出比例与执行环境中的真实露出比例。

在独立住宅中测量建模流程的类别、位置、朝向、尺寸、漏检和误检误差，用来构造扰动分布。已知布局的孪生作为上限对照，自动建出的孪生作为主流程。

这一阶段回答两个问题：换站位是否经常有帮助；模型是否足够准确，能够预测帮助在哪里。

## 6.2 单独评测四类判断

| 比较项 | 要回答的问题 |
| --- | --- |
| 规则加检测器、视觉判断、文字化判断、只用检测器 | 哪种输入与判断方式更有效 |
| 有参照／无参照 | 孪生参照是否带来帮助 |
| 深度掩码参照／RGB 外观参照 | 替代资产的外观差异如何影响判断 |
| 有目标照片／无目标照片 | 真实外观参考是否帮助识别目标 |
| 校准住宅／新住宅／后续跨引擎场景 | 置信度与正确频率是否能保持一致 |

报告四分类正确率、“挡住”和“空”的混淆率、Brier 分数、ECE、可靠性曲线和响应时间。Brier 与 ECE 用于检查模型给出的概率是否可信。

原方案建议从 30 套住宅采样，20 套用于训练与校准、10 套用于测试。训练和校准各自使用哪些住宅或样本，还需要在实现前明确。标签重叠与灰区也需要先确定。

## 6.3 运行完整任务

混合找物、去某处、家庭状态问答与长期要求，按“出现、暂时看不见、确认移走、再次出现”四阶段运行。

原方案建议 30 套关键位置住宅与 30 个开阔位置。观察额外路程按 5、10、20 米三档设置，每个任务最多询问主人一次。关键位置指避让范围会影响必经通道的位置。

| 对照或消融 | 检查什么 |
| --- | --- |
| 保守执行、边走边看、每次都问 | 完整方案相对简单策略的收益与开销 |
| 固定视角检查、沿原路线挑视角 | 主动改变观察位置的作用 |
| 超时撤销策略 | 基于证据更新要求状态的作用 |
| 文字化判断、只用检测器 | 四类视觉判断的作用 |
| 无局部校准、单一孪生、不替换候选资产 | 模型修正与误差处理各自的作用 |
| 无命题筛选、无参照渲染 | 任务相关筛选与参照的作用 |
| 已知布局孪生、知道真实状态的先知 | 建模与决策可能达到的上限 |

这些条目包括策略对照和组件消融。相关论文的完整方法能否在统一设定下复现，需要单独确认，不能把简化策略直接当成论文完整结果。

## 6.4 统一记录的指标

| 层面 | 指标 |
| --- | --- |
| 任务完成 | 各任务成功率、回答正确率、总用时 |
| 长期要求 | 违反次数、无谓绕行路程、过早暂停、未恢复、身份认错 |
| 观察开销 | 额外路程、观察位置数量、提问次数 |
| 判断质量 | 分类正确率、混淆率、概率校准、响应时间 |
| 建模质量 | 几何误差、检测错误、可见度预测误差 |

方法之间保持任务、住宅、执行器与观察预算一致；按住宅隔离参数调整、校准和最终测试。模拟器真值用于评估和离线标注，任务执行模块不得读取当前隐藏状态。

## 6.5 实施顺序与继续条件

1. 跑通自动建模、同位姿深度渲染和掩码输出。
2. 检查关键位置是否常见，以及换站位是否能看清。
3. 检查参照是否减少“挡住”和“空”的混淆。
4. 运行完整任务，分别观察违反要求和无谓绕行是否改善。
5. 条件满足后迁移到 Isaac Sim，再检查跨引擎与真实视频。

如果换站位很少有帮助，应重新选择任务范围；如果参照没有帮助，应重新判断视觉参照是否值得作为核心机制。具体取舍由测量结果支持，记录到 [08 设计约定与决策记录](08-decisions.md)。
