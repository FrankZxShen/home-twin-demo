## 6.1 离线检查 A：先检查站位与补全

| 假设 | 记录什么 | 解释边界 |
| --- | --- | --- |
| H1 | 原路线／预设视角看清率，额外移动后看清率 | 刻意选择的 30 个关键位置只说明这些位置的效果；判断家庭中的常见程度还需独立采样并保留分母 |
| H3 | 实际露出比例落入候选预测范围的比例，以及范围宽度和预测误差 | 很宽的范围容易覆盖真值，需同时报告是否仍能区分站位 |
| H4 | 相同候选集合下，不同方法选出的站位实际看清率和额外路程 | 单独报告视线经过未知区域的样本，并检查预测改进是否转化为站位收益 |

另外测量建图的类别正确率、位置／朝向／尺寸误差、mAP25、漏检和误检。用开发住宅估计误差模型，留出住宅检查迁移。

离线检查 A 先采用几何可见度评分。完成 B 的判断器校准后，再检查使用 ρ 的完整站位评分；两个结果分别报告。

## 6.2 最强简单对照

主要对照 B9 是**语义三维地图 + 主动站位选择 + 相同判断器**。它也允许离开原路线、保留未知区域并更新观测。所有方法共享初始视频、地图、可到达候选集合、执行器和观察预算。

以下是区分补全与采样作用所需的比较项，具体实现配置待讨论：

| 比较项 | 要分清什么 |
| --- | --- |
| 单一语义地图，明确未知区域的处理规则 | 原始地图已经能做到多少 |
| 同一地图加检索第一名的一次确定补全 | 补出形状本身的作用 |
| 多种资产补全 | 候选形状差异是否改善选站位 |
| 只按实测几何误差采样，不替换资产 | 收益来自一般误差处理，还是资产形状候选 |
| 真值布局／当前状态先知 | 几何预测和完整决策的诊断上限，单列报告 |

固定视角、沿路观察和超时撤销保留为简单策略。相关论文完整方法的复现范围见 [05](05-related-work.md)。

## 6.3 离线实验 B：四类判断

计划从 30 套住宅采样，20 套作为开发池、10 套作最终测试。开发池内区分参数选择与校准，具体划分待定。本轮不训练导航策略，也不要求微调 VLM。

比较 VLM 图像判断、文字／JSON 选项判断、规则版和检测器版。文字版可用 Jev，图像版也可评估其图像接口；输入差别和模型差别分开比较。

条件包括无噪声深度、加噪声深度、RGB-only、相似物体替换，以及有／无目标照片和有／无渲染参照。无噪声深度规则若与标签规则相同，只用于实现检查。

报告四分类准确率、“挡住/空”混淆、Brier、ECE、可靠性曲线和响应时间。先固定标签优先级、灰区与似然计算，再生成数据。最终测试住宅不得用于重新校准。

## 6.4 后续在线实验 C

混合找物、去某处、家庭问答和长期要求，按“出现、暂时看不见、确认移走、再次出现”四阶段运行。计划设置 30 个关键位置与 30 个开阔位置，每套住宅运行四天序列；位置与住宅的对应关系待固定。

观察额外路程按 5、10、20 米三档，每任务最多问主人一次。所有对照同预算、同输入，模拟器隐藏真值只供离线标注和评估。

分别报告任务成功率、问答正确率、违规次数、无谓绕行、过早暂停、未恢复、身份认错、观察路程、次数与耗时。额外记录建图和 K 场景评分的时间及存储开销。

纸箱在／不在的成对场景必须能改变合理行动。如果遮挡物本身已迫使两种配置走同一条路线，不能用该样本证明导航收益。

## 6.5 继续条件

先完成建图和补全检查，再做 A、B，最后决定是否进入完整在线实验。H1 不成立时收窄适用任务；H3 不成立时检查补全覆盖；H4 不成立时重新判断资产补全是否值得保留。

实际收益阈值可用开发集或小规模先导实验确定，但必须在最终测试前固定，不能看完测试效果再定义“成功”。渲染参照无收益时去掉该可选输入；这与 H4 的主线判断分开。

本轮只完成方案核验，尚未执行这些实验。
