# 03 具体方法

[返回首页](../README.md) · [上一章：核心 idea](02-idea.md) · [下一章：工具与实现](04-tools.md)

本章对应 2026-11-04 的地图主导方案。现有 PNG 是旧方案示意，版本差别见[图说明](../figures/README.md)。

## 3.1 输入与输出

输入包括住宅导览 RGB 视频、独立三维资产库、主人指令、已有记忆，以及运行时的 RGB-D 和机器人位姿。输出包括下一步动作、物体状态信念、长期要求状态及有观测依据的回复。

本轮不训练导航策略。建图误差估计、判断器概率校准和决策参数选择使用开发数据；留出测试住宅不参与调整。

## 3.2 从视频建立语义地图

1. 用 MASt3R 估计几何与相机位姿，解决与导航坐标的尺度对齐。
2. 用开放词汇检测器和 SAM 2 得到物体区域，跨帧融合类别、三维框及目标照片。
3. 提取墙、门和地面，构建语义地图 M，区分已观察表面、已知自由空间和未知空间。结构提取组件待选。
4. 新 RGB-D 观测用于更新地图；局部配准修正几何的位置误差。

主流程从视频恢复地图。直接读取模拟器布局只用于上限或标明“墙体布局已知”的诊断条件。

## 3.3 用资产补出可能的家

按 CLIP 类别、三维框几何适配和 DINOv2 外观相似度检索，默认保留前 5 名。检索用 Objaverse 等资产，执行环境用 ProcTHOR 资产，并检查重复模型。

默认生成 K = 20 个可能场景 H_k。资产提供未知部分的形状候选；位置、朝向、尺寸、漏检和误检的变化范围依据开发住宅中的建图误差估计。

生成结果必须服从已有观测约束。观测一致性与几何扰动需采用统一的误差约定：实现前明确哪些表面固定、哪些参数允许在误差范围内变化，以及冲突如何裁剪。这里尚未有验证通过的补全算法。新观测进入地图后，更新候选场景。

## 3.4 决定要确认什么、去哪里看

把任务依赖的信息记为命题 z，例如“纸箱仍在走廊原位置”，维护其为真的概率 b(z)。分别按 z 为真和为假生成计划，只有动作或回答不同才继续取证。

在可通行区域采样站位及朝向，保留原路线候选。站位和到达路线须满足观察预算与当前生效的要求。

每个 H_k 预测目标区域的露出比例与观察距离，再查判断器的离线标定表，得到 ρ_k(s)：在站位 s 得到“在”或“空”且判断正确的概率。

```text
站位得分(s) = Q20({ρ_k(s)}) − β × 额外路程(s)
```

Q20 是样本的第 20 百分位数，β 权衡分辨机会和路程。K、分位数及 β 都是待验证配置。这个评分偏向较不利补全下仍有效的站位，并不保证真实环境一定落在候选范围内。

最好的观察动作再与“问主人”“直接执行”比较期望代价。代价包含路程、违反要求、无谓绕行及主人时间；最终评测仍分别报告这些量。

离线检查 A 先测几何露出比例和站位是否有效。判断器的 ρ 标定表由离线实验 B 得到，随后再验证完整评分，避免在取得标定数据之前假定其已可用。

## 3.5 到达后，用实际观测回答四选一

| 输入 | 用途 |
| --- | --- |
| 当前 RGB-D、位姿、目标区域 | 现场视觉和几何证据 |
| 目标照片 | 区分目标与相似物体 |
| 实测深度得到的遮挡信息 | 帮助判断目标区域是否看清 |
| 可选的同位姿深度与掩码参照 | 比较目标在／不在时的几何差别，用消融检验作用 |

| 输出 | 含义 | 更新作用 |
| --- | --- | --- |
| 在（Present） | 有足够视觉证据识别到目标 | 支持在场 |
| 空（Empty） | 目标区域已充分看清，目标未出现 | 支持不在该区域 |
| 挡住（Occluded） | 区域被遮挡，无法判断目标在不在 | 保留存在性不确定性 |
| 看不清（Unclear） | 距离、光照或模糊等使判断不足 | 保留存在性不确定性 |

“挡住”描述观察条件，不能推断遮挡后面一定有目标。部分可见、遮挡与低质量并存时的标签优先级，需要在生成数据前确定。

判断器在开发住宅上校准，再通过混淆模型得到观测似然，用贝叶斯公式更新 b(z)。输出的选项概率不能直接当作存在性后验。软概率到似然的具体计算仍需固定；“挡住”和“看不清”应只提供很弱的存在性证据。同站位的相邻帧按一轮证据处理。

## 3.6 更新要求与继续任务

| 要求状态 | 含义 |
| --- | --- |
| 生效 | 当前在该物体附近执行 |
| 待确认 | 证据不足，需要进一步判断 |
| 暂停 | 足够证据支持物体离开原位置，暂停原位置约束 |
| 撤销 | 主人明确取消要求 |

要求绑定具体物体。在别处确认同一个物体后，在新位置恢复。几何观测写回地图，尚有疑点及预算时重新选站位；预算用完则报告已检查范围和未解决的信息。

## 3.7 系统模块

| 模块 | 负责什么 |
| --- | --- |
| G1 解析与分流 | 识别任务、要求与外部工具问题 |
| G2 家庭记忆 | 维护地图、可能场景、物体信念和要求 |
| G3 任务规划 | 找出会改变动作或回答的命题 |
| G4 取证决策 | 选站位，比较观察、询问和直接执行 |
| G5 观测更新 | 区域判断、身份判断、信念与地图更新 |
| G6 执行器 | 导航、拍照、询问和调用工具 |
| G7 完成检查 | 检查完成条件的证据并回复 |
