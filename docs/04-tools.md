# 04 工具与实现

[返回首页](../README.md) · [上一章：具体方法](03-method.md) · [下一章：相关工作](05-related-work.md)

本页列出计划使用或候选的组件。它们在本项目中的组合尚未完成实现与评测。

## 4.1 UrbanVerse：建场景的流程参考

UrbanVerse 从城市导览视频提取布局，检索三维资产，并组装交互仿真场景。当前方案借用“视频、几何与物体提取、资产检索、场景拼装”这条流程，增加室内结构和带关节部件的处理。[论文](https://arxiv.org/html/2510.15018)

本项目需要自行测量室内建模误差，再把孪生用于任务执行中的观察预测。UrbanVerse 的室外误差不能直接作为本项目的室内误差。

## 4.2 Jev：小判断的接口参考和候选模型

Jev 的 Choice 接口接收状态、问题与选项，返回选择、概率和置信度。代码可以组合多个独立的小判断。[官方文档](https://docs.typesafe.ai/primitives)

当前方案在任务分类、区域情况、物体身份、主人回答和任务完成等位置采用这种写法。路程、几何、站位评分、代价比较和记忆更新由代码执行。

Jev 在 2026-10-14 开放了实验性图像输入，因此可以列入视觉判断候选。图像功能的可靠性仍需测试。[官方公告](https://typesafe.ai/blog/jev-1-14)

为了分清不同因素，保留两个独立的比较问题：文字化状态与直接看图的差别；不同视觉模型在相同输入下的差别。使用 Jev 图像输入不会自动回答前一个问题。

接口可用性、响应时间、深度参照的处理效果和家庭数据上的概率校准，都属于待验证项。

## 4.4 执行环境与孪生的分工

| 阶段 | 机器人执行任务的环境 | 机器人使用的孪生 |
| --- | --- | --- |
| 原型 | AI2-THOR + ProcTHOR | 从执行环境的 RGB 导览视频自动建出，用独立网格渲染器渲染 |
| 后续主实验 | Isaac Sim 中的 NuRec 重建住宅或 GRScenes 类场景 | 同一建模流程得到的 USD 场景 |
| 跨引擎检查 | UE5 / UnrealZoo 中的室内场景 | 用于检验四类判断及校准能否迁移 |

NuRec 在这里提供后续执行环境的候选来源。3DGS 场景与网格物体混用时，遮挡、深度和掩码是否一致，需要先做小例子验证。

## 4.5 实现前要确定的接口

- 视频几何恢复的尺度怎样与机器人导航尺度一致。
- 墙、门、地面由哪个组件提取。
- 三维资产的类别、尺寸、关节状态如何统一。
- 判断模型如何接收深度图、掩码和目标照片。
- 位置误差、模型置信度和观测似然如何记录，避免混用。
