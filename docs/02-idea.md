# 02 核心 idea

[返回首页](../README.md) · [上一章：问题与任务](01-problem.md) · [下一章：具体方法](03-method.md)

## 2.1 问题在选观察位置时就出现了

机器人知道纸箱上次在哪里，但不知道现在是否还在。它想换个位置观察，却只掌握导览视频拍到的部分。柜子背面、进深或门后的结构不完整时，只按一种形状预测，选出的站位可能仍然被挡住。

## 2.2 地图为主，相似资产补未知部分

语义三维地图保存已观察表面、物体和未知区域。参照 UrbanVerse 的资产检索流程，为物体保留多个相似模型，组合成多个可能的家。

各个可能场景共享观测支持的地图，差别主要来自未观测的形状和实测误差。资产与已有观测冲突时，以观测为约束。如何对齐、裁剪和设置误差容差仍是待实现的关键步骤。

例如，视频只拍到柜子正面。候选资产的进深不同，靠近柜子的侧面站位可能只在一部分场景中有效。稍远的位置如果在更多场景中都能看清，就可能更值得走过去。

## 2.3 出发前预测，到达后取证

出发前比较候选站位在多个可能场景中的分辨机会，并计入额外路程。到达后用实际图像判断“在、空、挡住、看不清”。地图渲染的参照属于可选输入，是否保留由消融决定。

只验证会改变动作或回答的命题。代码负责几何计算、站位评分和信念更新；VLM 或 Jev 式判断工具回答范围明确的小问题。

## 2.4 当前候选贡献

候选主张是：**受已有观测约束的多种资产补全，能改善任务执行时的观察站位选择。** 主动观察、遮挡处理和不确定性建模已有相关方法，不能单独当作本工作的创新。针对这一组合机制的查新尚未完成，见 [05](05-related-work.md)。

| 假设 | 要验证的内容 |
| --- | --- |
| H1 | 原路线看不清、换站位能看清的情况在目标任务中有实际比例 |
| H3 | 多个可能场景对露出比例的预测能覆盖实际情况，且范围不过宽 |
| H4 | 同样地图、候选位置、判断工具和预算下，多个可能场景比单一地图或确定补全更常选到有效站位 |
| H5 | 到站判断能区分遮挡和空区域，概率校准可迁移到留出住宅 |

H1、H3、H4 是当前主线的优先检查项。若 H4 没有收益，资产补全作为方法贡献的依据就不足；后续方向需根据结果重新讨论。渲染参照无收益时，可以去掉该可选输入，不影响对站位选择本身的检验。
